1. zip を開く

ダウンロードした zip をダブルクリックすると、「karuta-edit」フォルダができます。中の karuta-edit.app がアプリです。

karuta-edit.app を「アプリケーション」フォルダに移しておくと、あとで探しやすくなります（移さなくても使えます）。

2. 初めて開く（警告が出たとき）

  1. karuta-edit.app をダブルクリックします。次のような表示が出たら、「完了」を押して閉じます。「ゴミ箱に入れる」は押さないでください。

    “karuta-edit”は開いていません

    Apple は、“karuta-edit”に Mac に損害を与えたり、プライバシーを侵害する可能性のあるマルウェアが含まれていないことを検証できませんでした。

    ゴミ箱に入れる完了

    文言は macOS の版によって少し違います。

  2. 画面左上の Apple メニューから「システム設定」を開き、「プライバシーとセキュリティ」を選びます。

  3. 右側を下までスクロールすると、「セキュリティ」の欄に karuta-edit がブロックされたことが出ています。その横の「このまま開く」を押します。

    この表示は、手順1のあと1時間ほどで消えます。見当たらないときは、もう一度手順1からやり直してください。

  4. もう一度確認が出るので、「このまま開く」を押し、Mac のパスワード（または Touch ID）を入れます。

これで開きます。次からは、karuta-edit.app をダブルクリックするだけで開けます。

「右クリック →『開く』」では開けません。以前の macOS ではこの方法で開けましたが、macOS 15 以降は上の手順が必要です。

「“karuta-edit”は壊れているため開けません」と出たとき

ダウンロードの仕方によっては、上の手順の代わりにこの表示が出ることがあります。そのときは「ターミナル」（アプリケーション → ユーティリティ）を開き、次の文字を入れてから、karuta-edit.app をターミナルの画面にドラッグして、return を押します。

xattr -dr com.apple.quarantine

末尾の空白のあとに、karuta-edit.app の場所が入ります。実行したあとは、ダブルクリックで開けます。

3. 動画のフォルダへのアクセスを許可する

「ダウンロード」「デスクトップ」「書類」フォルダにある動画を初めて選ぶと、次のような確認が出ます。「許可」を押してください。

“karuta-edit”から“ダウンロード”フォルダ内のファイルにアクセスしようとしています。

許可しない許可

文言は macOS の版によって少し違います。

確認はフォルダごとに1回だけ出ます。この確認に答えるまで、アプリは動画を読めず、画面が「動画を選ぶ」のまま進みません。ほかのウィンドウの後ろに隠れていることがあります。

「許可しない」を押してしまったとき

「システム設定」→「プライバシーとセキュリティ」→「ファイルとフォルダ」を開き、karuta-edit の下にある、そのフォルダのスイッチをオンにします。

新しい版の karuta-edit に入れ替えたときは、もう一度確認が出ることがあります。

4. 使いかた

karuta-edit.app を開くと、しばらくしてブラウザ（Safari や Chrome など、いつも使っているもの）で「かるた動画の短縮」の画面が開きます。

  1. 動画を選ぶ：「ファイルを選択...」で試合の動画を選び、「解析を始める」を押します。

  2. 解析：読みの場面を探し、読まれた歌を聞き分けます。1時間ほどの試合で数分かかります。

  3. 確認：歌が分からなかった場面だけ、残すか外すかを選びます。確かめずに進んでもかまいません。

  4. 書き出し：「短縮版を作る」で短縮版を作り、「保存する」で保存します。保存先は、ブラウザのダウンロード先（ふつうは「ダウンロード」フォルダ）です。

初めて歌の聞き分けを使うときは、音声認識のデータ（約630 MB）のダウンロードに数分かかります。2回目からは要りません。インターネットにつながらないときは、「詳細設定」の「読まれた歌を特定する」をオフにすれば、聞き分けなしで短縮版を作れます。

5. 終わりかた

macOS 版は、Dock にもメニューバーにも出ず、裏で動きます。ブラウザのタブを閉じても終わりません。終わるときは、次のようにします。

  1. 「アクティビティモニタ」（アプリケーション → ユーティリティ）を開きます。

  2. 一覧から karuta-edit を選び、上の ⊗ ボタンを押して「終了」を選びます。

  3. しばらくしても一覧から消えないときは、もう一度 ⊗ ボタンを押して「強制終了」を選びます。保存していない短縮版は消えるので、保存してから終わらせてください。

Mac を再起動したりログアウトしたりしても終わります。動いたまま karuta-edit.app をもう一度開くと、2つ目が動き、ブラウザに新しいタブが開きます。

6. 困ったとき

ブラウザの画面が開かないブラウザで http://localhost:8501 を開いてください。karuta-edit を2つ以上動かしているときは、8502、8503 と番号が増えます。
動画を選んでも進まないフォルダへのアクセスの確認（3）が、ほかのウィンドウの後ろに出ていないか確かめてください。
歌の聞き分けができなかったと出るインターネットにつながっているか確かめてください。つながらないときは、「詳細設定」で「読まれた歌を特定する」をオフにして進められます。
保存した短縮版が見つからないブラウザのダウンロードの一覧を開いてください。「保存する」は何度でも押せます。

7. 削除するとき

karuta-edit.app をゴミ箱に入れます。音声認識のデータ（約630 MB）も消すときは、Finder の「移動」→「フォルダへ移動...」で ~/Library/Caches/karuta-edit を開き、そのフォルダをゴミ箱に入れます。
