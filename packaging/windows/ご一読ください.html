1. zip を展開する

ダウンロードした zip を右クリックし、「すべて展開」を選びます。展開先は、デスクトップやドキュメントなど、わかりやすい場所にしてください。

展開したフォルダの中の「karuta-edit」フォルダに、アプリの karuta-edit.exe と、動かすためのファイルが入った「_internal」フォルダがあります。この2つは同じフォルダに置いたまま使ってください。

zip を開いただけの状態で karuta-edit.exe をダブルクリックしても動きません。必ず「すべて展開」してから開いてください。

2. 初めて開く（警告が出たとき）

  1. karuta-edit.exe をダブルクリックします。次のような青い画面が出たら、「詳細情報」を押します。

    Windows によって PC が保護されました

    Microsoft Defender SmartScreen は認識されないアプリの起動を停止しました。このアプリを実行すると、PC に問題が起こる可能性があります。
    詳細情報

    実行しない

  2. 「アプリ: karuta-edit.exe」「発行元: 不明な発行元」と出て、下に「実行」のボタンが現れます。「実行」を押します。

    アプリ: karuta-edit.exe
    発行元: 不明な発行元

    実行実行しない

    文言は Windows の版によって少し違います。

これで開きます。次からは、karuta-edit.exe をダブルクリックするだけで開けます。

Windows 11 で「スマート アプリ コントロール」がオンになっていると、署名のないアプリはこの手順でも開けず、「ブロックされました」と出ます。オフにする方法はありますが、パソコン全体の守りが弱くなるため、配布した人に相談してください。

3. ファイアウォールの確認が出たとき

初めて開いたとき、「Windows セキュリティの重要な警告」として、karuta-edit の通信を許可するかを尋ねられることがあります。

Windows セキュリティの重要な警告

このアプリの機能のいくつかが Windows Defender ファイアウォールでブロックされています

アクセスを許可するキャンセル

文言は Windows の版によって少し違います（「Windows Defender ファイアウォール」が「Windows ファイアウォール」となっていることもあります）。

このパソコンだけで使うなら、「キャンセル」で大丈夫です。スマートフォンなど、同じネットワークのほかの端末から画面を開いて使いたいときだけ、「プライベート ネットワーク」にチェックを入れて「アクセスを許可する」を押します。

4. 使いかた

karuta-edit.exe を開くと、黒い画面（ログの画面）が開き、しばらくしてブラウザ（Edge や Chrome など、いつも使っているもの）で「かるた動画の短縮」の画面が開きます。黒い画面は、使い終わるまで閉じないでください。閉じるとアプリが終わります。

  1. 動画を選ぶ：「ファイルを選択...」で試合の動画を選び、「解析を始める」を押します。ファイルを選ぶ画面は、ブラウザの後ろに開くことがあります。

  2. 解析：読みの場面を探し、読まれた歌を聞き分けます。1時間ほどの試合で数分かかります。

  3. 確認：歌が分からなかった場面だけ、残すか外すかを選びます。確かめずに進んでもかまいません。

  4. 書き出し：「短縮版を作る」で短縮版を作り、「保存する」で保存します。保存先は、ブラウザのダウンロード先（ふつうは「ダウンロード」フォルダ）です。

初めて歌の聞き分けを使うときは、音声認識のデータ（約630 MB）のダウンロードに数分かかります。2回目からは要りません。インターネットにつながらないときは、「詳細設定」の「読まれた歌を特定する」をオフにすれば、聞き分けなしで短縮版を作れます。

5. 終わりかた

黒い画面を、右上の × で閉じます。ブラウザのタブを閉じただけでは終わりません。

6. 困ったとき

ブラウザの画面が開かないブラウザで http://localhost:8501 を開いてください。karuta-edit を2つ以上開いているときは、8502、8503 と番号が増えます。
黒い画面がすぐ消える「_internal」フォルダが karuta-edit.exe と同じ場所にあるか確かめてください。zip を展開せずに開いたときもこうなります。
ウイルス対策ソフトに消された署名のないアプリは、ウイルス対策ソフトに誤って疑われることがあります。消されたり隔離されたりしたときは、配布した人に知らせてください。
歌の聞き分けができなかったと出るインターネットにつながっているか確かめてください。つながらないときは、「詳細設定」で「読まれた歌を特定する」をオフにして進められます。
保存した短縮版が見つからないブラウザのダウンロードの一覧を開いてください。「保存する」は何度でも押せます。

7. 削除するとき

展開したフォルダごと削除します。音声認識のデータ（約630 MB）も消すときは、エクスプローラーのアドレス欄に %LOCALAPPDATA% と入れて開き、中の「karuta-edit」フォルダを削除します。
